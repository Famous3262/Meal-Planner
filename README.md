# GlowMeal — Meal Planner

A React Native meal-planning application built with Expo. The current app includes an onboarding flow, a daily meal-planning view, recipe browsing, a weekly timetable and a grocery list.

> **Project status:** Development project. Features and integrations may change as the application evolves.

## Current functionality

- Account flow with landing, login and signup screens
- Onboarding wizard for collecting a user profile
- Local profile persistence with AsyncStorage
- Daily meal recommendations generated from the saved profile
- Planner, weekly timetable, recipes and grocery navigation
- Meal-plan state shared between planner screens

## Technology

- React Native 0.81
- Expo SDK 54
- React 19
- JavaScript
- AsyncStorage
- React Navigation

## Run locally

### Prerequisites

- Node.js (LTS recommended)
- npm
- Expo Go on a compatible device, or an Android/iOS development environment

### Setup

```bash
git clone https://github.com/Famous3262/Meal-Planner.git
cd Meal-Planner
npm install
npx expo start
```

Use the Expo CLI options to open the project in Expo Go, an Android emulator, an iOS simulator or a web browser where supported.


## Notes

- User profile data is currently persisted locally using AsyncStorage.
- Meal recommendations are generated by the app's recommendation utility.
- Do not assume cloud sync or a production backend is configured unless one is added and documented.
